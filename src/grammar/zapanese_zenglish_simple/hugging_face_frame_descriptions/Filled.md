# Zapanese to Zenglish: filled sentences

Synthetic sentence pairs for studying whether language models use hierarchical
syntactic structure when translating between a head-final and a head-initial word
order.

- **Zapanese** is English vocabulary in Japanese word order: verb last, relative
  clause before the noun it modifies, and explicit case markers (`NOM`, `ACC`).
  Objects may be *scrambled* in front of the subject.
- **Zenglish** is the same vocabulary in head-initial order: subject, verb, object,
  with the relative clause after its noun. Scrambled and unscrambled Zapanese
  sentences translate to the *same* Zenglish sentence.

Every sentence instantiates one of 18 syntactic **frames** (see the companion
[frames dataset](https://huggingface.co/datasets/kylelovesllms/zapanese_zenglish_simple-frames)).
The frames are partitioned into in-distribution and out-of-distribution sets so that
a model trained on `train` can be tested on constructions it has never seen.

Generated by the `zapanese_zenglish_simple` experiment in
[Ky-Ng/tbd-syntax](https://github.com/Ky-Ng/tbd-syntax)
(`src/grammar/zapanese_zenglish_simple/run.py generate`).

## Example rows

| frame_id | source (Zapanese) | target (Zenglish) |
|---|---|---|
| F01 | `cat NOM rabbit ACC bites` | `cat NOM bites rabbit ACC` |
| F02 | `rabbit ACC cat NOM bites` | `cat NOM bites rabbit ACC` |
| F04 | `goat NOM owl ACC sees dog ACC touches` | `goat NOM touches dog ACC sees owl ACC` |

In F04 the relative clause `owl ACC sees` ("that sees the owl") modifies `dog`, the
object. Brackets are never present in the data; read the frame table below to see
the structure.

## Columns

| Column | Type | Meaning |
|---|---|---|
| `frame_id` | string | Which of the 18 frames the sentence instantiates (`F01` … `F18`). |
| `frame_split` | string | Frame-level split of that frame: `train`, `ood_level1` or `ood_level2`. |
| `subset` | string | Filling-level subset; equals the split name this row is in. |
| `source` | string | Zapanese sentence, whitespace-tokenised. |
| `target` | string | Zenglish translation, whitespace-tokenised. |

**Tokenisation.** Split on whitespace. A noun and its case marker are two tokens
(`dog NOM`). There is no complementizer ("that") and no punctuation. The vocabulary
has 54 types: 26 nouns, 13 transitive verbs, 13 intransitive verbs, and the two case
markers `NOM` and `ACC`.

## Splits

| Split | Frames | Rows | Intended use |
|---|---|---|---|
| `train` | F11 F01 F02 F03 F12 F16 F18 F08 F15 | 7504 | fitting |
| `dev` | same frames, different sentences | 834 | early stopping / in-distribution model selection |
| `ood_level1_select` | F10 F05 F17 | 1500 | choosing checkpoints for analysis |
| `ood_level1_report` | same frames, different sentences | 1500 | reported Level 1 accuracy |
| `ood_level2_select` | F04 F13 F06 F07 F09 F14 | 3000 | choosing checkpoints for analysis |
| `ood_level2_report` | same frames, different sentences | 3000 | reported Level 2 accuracy |

What each frame split tests:

- **train**: no relative clause, or a relative clause on the *first* noun with a
  *subject* gap. The embedded noun is always `ACC`. A linear heuristic suffices: the
  noun right before the matrix verb tells you whether the sentence is scrambled, and
  the relative clause translates by reversing `noun case` chunks.
- **ood_level1**: relative clause still on the first noun, but with an *object* gap.
  Chunk reversal gives the wrong order, and the sentence contains two `NOM` nouns.
- **ood_level2**: relative clause on the *second* noun. The noun before the matrix
  verb no longer identifies the construction.

`select` and `report` contain the same frames with disjoint sentences. The intended
protocol is to pick checkpoints on `select` (or on `dev`) and publish accuracy from
`report`, per frame, so that no reported number was selected on.

## Sampling

For every frame, 1000 fillings were drawn **without replacement** from all
lexicalisations of that frame (seed 0, independent stream per frame), shuffled, and
cut into the subsets above (90/10 for train frames, 50/50 for OOD frames). The same
word may fill several slots (`yak NOM yak ACC likes` is legal). Frame F11
(`SUBJ NOM VERB`) has only 338 possible sentences, so it contributes 338 rows
instead of 1000. No sentence appears in two subsets.

## The 18 frames

`[...]` marks the relative clause and `__` its gap; both are reading aids only.

Several Zapanese frames share a Zenglish frame (F01/F02, F03/F07, F12/F14, F08/F04,
F15/F13, F05/F09, F10/F06). In every pair except F01/F02, one member is in `train`
and the other is out of distribution.

## Loading

```python
from datasets import load_dataset

ds = load_dataset("kylelovesllms/zapanese_zenglish_simple-filled")
ds["train"], ds["dev"]                              # fitting and early stopping
ds["ood_level1_report"], ds["ood_level2_report"]    # reported accuracy

# one frame at a time, e.g. for per-frame accuracy
f04 = ds["ood_level2_report"].filter(lambda row: row["frame_id"] == "F04")
for row in f04:
    row["source"], row["target"]
```

## Vocabulary

- Nouns (26): aardvark, bird, cat, dog, elephant, fox, goat, horse, iguana, jaguar,
  koala, lion, mouse, newt, owl, pig, quail, rabbit, snake, tiger, urchin, vulture,
  wolf, xerus, yak, zebra
- Transitive verbs (13): chases, sees, follows, likes, bites, hears, pushes, finds,
  hugs, kicks, watches, carries, touches
- Intransitive verbs (13): swims, dances, sleeps, runs, jumps, sits, laughs, waits,
  flies, hides, sings, walks, crawls
- Case markers: NOM, ACC
